# 英文構造アナライザー

TOEIC 対策向けの英文学習アプリです。集めた英文を AI(Gemini)で構造化し、グループ化・関係図・イラスト・音声で学習します。
ブラウザだけで動く静的サイト(PWA)で、スマホのホーム画面に追加して使えます。

- 公開版: https://eng-analyzer.scratch-2026-10-07-cb3f9c.workers.dev
- 参考: [英文構造を一発で分解するアプリ(Qiita)](https://qiita.com/oguro_swada/items/17bc234b152a5ae6d0a1)(OCR 機能は除いています)

## モード

| モード | 内容 |
|---|---|
| ⑴ 構造化 | 和訳・スラッシュリーディング・**区切りごとの形**・品詞の色分け・SVOC・5文型・時制/文法・単語・TOEIC の観点・Part 5 風 4択問題 |
| ⑵ 英文グループ化 | 解析結果からの自動分類(API 不要)/ AI によるグループ案 |
| ⑶ 関係図化 | [RelaGrid](https://github.com/minnanosaiban/relagrid) で S/V/O/C/M・節の関係を図示 |
| ⑷ イラスト化 | OpenMoji の絵文字シーン / AI による簡易 SVG イラスト |
| ⑸ 英単語グループ化 | 単語帳と、品詞・頻出度・意味などによるグループ分け |
| 弱点集計 | 間違えた文法分類を、直近7日・30日・全期間で集計。分類から、その英文の一覧へ移動 |
| 英文生成 | テーマ・文法項目・難易度・件数を指定して、TOEIC風のオリジナル英文を AI が作成。採用した英文だけを追加 |

### 区切りごとの形(⑴ 構造化)

英文を、文法上のまとまりごとに、前から順に区切り、番号と**形**を付けて説明します。例:

```
⑴ Candidates are advised:主語+動詞
⑵ to bring copies of their certificates:to+不定詞句
⑶ to the interview:前置詞句
```

- 形は、主語+動詞(+目的語/補語)、to+不定詞句、動名詞句、分詞句、前置詞句、副詞(句)、接続詞+節(副詞節)、関係詞節、名詞節(that節)などです。命令文には、主語がないので「動詞+目的語(命令文)」のように付きます。
- 画面には、番号と下線つきの文と、区切りごとの一覧(形のラベルつき。色は、節・準動詞・前置詞・文の核で分けます)が出ます。「テキストでコピー」で、上の書式のテキストをコピーできます。
- AI の返事は、区切りをつなぐと原文と完全に一致するときだけ採用します。合わなければ、区切りの形だけを付けません(解析の他の部分は残ります)。
- 新しく解析した英文には、はじめから付きます。すでに解析した英文には、「区切りの形を付ける」(1文)、ライブラリの「表示中の品詞・区切りの形を一括で付ける」(API は1文ずつ、コピペモードは10文ずつ)で足せます。受信箱・復元で同じ英文が届いたときも、区切りが無い英文には足されます(解析結果は上書きしません)。

### 発音記号(IPA)

- 単語(⑴ の「単語・熟語」、単語帳)に、アメリカ英語の発音記号を `/ˈæplɪkənt/` の形で出します。🔊 で、実際の読み上げも聞けます。
- 新しく解析した英文の単語には、AI が付けます。AI の発音記号は誤りが混じることがあるので、気になる語は辞書で確かめてください。
- samples の単語 379 語は、AI ではなく、発音辞書(CMU Pronouncing Dictionary、アメリカ英語)から機械的に作りました。熟語は語ごとにつなぎ、of・to などの機能語は弱い発音にしています。辞書に無い 3 語(résumé・repave・intranet)だけ手で付けています。
- 単語帳に追加すると、発音記号も引き継がれます。受信箱・復元・サンプル読み込みで同じ単語が届いたときは、発音記号が無い単語にだけ足します。
- 発音記号に使える文字だけを受け付けます(それ以外は捨てます)。

### 品詞の色分け(⑴ 構造化)

- 英文を単語ごとに分け、品詞(名詞・代名詞・動詞・助動詞・形容詞・副詞・前置詞・接続詞/関係詞・冠詞/限定詞・その他)ごとに、色と下線で表示します。「品詞名も表示」で、各語の下に品詞名を出せます。凡例の品詞名を押すと、その品詞だけが目立ちます。
- 新しく解析した英文には、はじめから付きます。AI の返答は、語を半角スペースでつなぐと原文と一致するときだけ採用し、合わなければ色分けだけを付けません(解析の他の部分は残ります)。
- すでに解析した英文には、「品詞を付ける」(1文)、ライブラリの「表示中の品詞を一括で付ける」(API は1文ずつ、コピペモードは10文ずつ)で足せます。
- 受信箱・復元で、同じ英文が届いたとき、品詞が無い英文には品詞だけを足します(解析結果は上書きしません)。

### 学習管理(⑴ 構造化の「学習管理」)

- **状態**: 英文・単語ごとに「未学習 / 学習中 / 覚えた」を手動で切り替えます(自動では変えません)。一覧・単語帳は、既定で「覚えた」を除いて表示します。ライブラリの「この条件で復習を始める」で、絞り込んだ英文だけを順にたどれます。
- **間違いの記録**: 4択問題で不正解だったとき、分類(品詞・時制・助動詞・受動態・前置詞・接続詞・関係詞・不定詞・動名詞・分詞・比較・語彙・構文把握・その他)を選んで記録できます。手動でも追加できます。
- **難易度の目安**: 600 / 730 / 860 点。AI の解析で自動設定し、手動でも変えられます。一覧で絞り込めます。
- **確認・修正**: AI の解析直後は「未確認」の目印が付きます。和訳・文型・時制・文の要素・文法ポイント・単語を手で直し、「確認済み」にできます。
- **復習回数**: 4択問題に答えたとき(英文)、隠した意味を見たとき(単語)に、復習回数と最終復習日が更新されます。

> 公式問題集などの市販教材から取り込んだ英文は、自分の学習用にとどめてください。配布・公開はしないでください(著作権は各権利者に帰属します)。

## 音声

音声は、専用の画面ではなく、**どの画面からでも**使えます。端末の読み上げ機能を使うので、無料・オフラインでも動きます。

- **1回読む**: ライブラリ・グループ一覧・単語帳・弱点集計・英文生成・4択問題など、英文や単語のある場所の ▶ ボタン。
- **続けて再生**: ライブラリ・グループ・単語帳の「この一覧を続けて再生」。画面の下に、小さなプレーヤー(前へ・次へ・一時停止・速さ)が出て、別の画面に移っても続きます。
- **音声練習**(⑴ 構造化の英文の画面): 区切りごとに聞く(読んでいる区切りが色付きになる)、シャドーイング(読んだあと、同じ長さの無音で、まねする時間を空ける)、聞き取り練習(英文を隠して聞き、入力して、語ごとに答え合わせ)。
- **設定**: 声・速さ・繰り返し・間・和訳や単語の意味を読むか、は、「設定 → 音声」の1か所です。すべての音声が、この設定を使います。

## すぐ試す(API キー不要)

「追加」タブの「**サンプル英文を入れる**」を押すと、TOEIC風のオリジナル英文 90文(`public/samples/`)が入ります。解析・品詞の色分け・4択問題・絵文字のイラスト・関係図が、はじめから付いているので、**API キーなしで、すべての機能を試せます**。同じ英文は重複して入らず、すでにある英文に足りないもの(品詞・問題・イラスト・関係図)があれば、足されます(解析結果・状態・間違いの記録は上書きしません)。

## データの保存とクラウド同期

- 英文・単語・グループ・解析結果は、まず各自のブラウザ(localStorage)に保存されます。API キーはブラウザ内だけで、同期しません。
- 「⚙ 設定」→「クラウド同期」を有効にすると、英文・単語・グループを **端末側で暗号化してから** Cloudflare D1 に保存し、PC とスマホで共有できます。
  - 暗号化: パスフレーズから PBKDF2(SHA-256・60万回)で鍵を作り、AES-GCM で暗号化。パスフレーズと鍵は送信しないため、サーバー側からは中身を読めません。パスフレーズを忘れると復元できません。
  - 認証: 初回作成時に発行される「同期キー」(保管庫ID.秘密)で接続します。2台目以降は、設定画面の QR コードをスマホで読み取ると同期キーが入力済みの状態で開きます(キーは URL の `#` 以降に入れるのでサーバーには送られません)。サーバーは秘密の SHA-256 だけを保存します。
  - 保管庫の作成にはセットアップコード(Worker のシークレット `SETUP_CODE`)が必要で、作成できる数は `MAX_VAULTS`(既定 1)までです。
  - 変更は数秒後に自動で同期されます。同じ英文が両方の端末にあれば1つにまとめます。
- **受信箱**: 「設定 → クラウド同期 → 受信箱」で、書き込み専用の合言葉を発行すると、Claude Code などが `tools/inbox-send.mjs` で英文を預けられます。預けられた英文は、アプリが次の同期で受け取って登録します。
  - 送る側は、英文を**公開鍵(RSA-OAEP)で暗号化**してから送ります(本文は1通ごとの AES-GCM 鍵で暗号化し、その鍵を公開鍵で包みます)。対応する秘密鍵は、保管庫の鍵(パスフレーズから作る)で暗号化してサーバーに置くので、復号できるのは、パスフレーズを知る端末だけです。
  - 合言葉は「預けること」しかできません(同期データの読み出し、受信箱の中身の閲覧はできません)。いつでも無効化・再発行できます。受信箱には、通数(200)・大きさ(20MB)の上限があります。
  - 受け取るときは、使う項目(英文・解析・難易度・グループ・単語)だけを取り出し、解析つきの英文は「未確認」にします。状態や復習回数などを外から書き換えることはできません。
  - 使い方は `CLAUDE.md` を参照してください。
- 「バックアップ保存」「復元」で JSON ファイルにも書き出せます(このファイルは暗号化されません)。

## AI の使い方

- **Gemini API**: 「⚙ 設定」で [Google AI Studio](https://aistudio.google.com/apikey) の API キーを入力します。呼び出しはボタンを押したときだけです。
- **コピペモード**: API キー不要。プロンプトをコピーして Gemini アプリ等に貼り、回答を貼り戻します(一括解析は 10 文ずつ)。

## 構成

```
public/            公開されるファイル一式
  index.html       アプリ本体(HTML/CSS/JS を1ファイルに)
  sw.js            Service Worker(オフライン用キャッシュ)
  manifest.json    PWA 設定
  relagrid/        RelaGrid の描画部分(minnanosaiban/relagrid の js/ からコピー)
  samples/         試すための英文(CSV と、解析済みの JSON)。アプリに同梱され、「サンプル英文を入れる」ボタンで読み込まれる
src/worker.js      同期 API(/api/*)。暗号文の保存・取得のみ
migrations/        D1 のテーブル定義(0001 同期、0002 受信箱)
tools/             inbox-send.mjs(受信箱へ英文を預ける)
CLAUDE.md          Claude Code が英文を入れる手順
wrangler.jsonc     Cloudflare Workers(静的アセット + D1)の設定
```

## ローカルで動かす

```bash
npx wrangler d1 migrations apply eng-analyzer-db --local
```

```bash
npx wrangler dev
```

ローカルでセットアップコードを使う場合は `.dev.vars` に `SETUP_CODE=...` を書きます(Git 管理外)。

## 公開(Cloudflare)

```bash
npx wrangler deploy
```

`public/sw.js` の `CACHE` の版番号を上げると、利用者の端末のキャッシュが更新されます。
